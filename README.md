# LexiForge 🧱🗣️

**Forge Fluent Sentences, Brick by Brick**

Welcome to **LexiForge**, a comprehensive, community-driven English grammar and composition laboratory. Unlike static exercise books, LexiForge is a living, breathing ecosystem where language learners and polyglots build structural mastery through interactive "sentence smithing." Think of grammar not as a set of rules to memorize, but as a palette of malleable materials—and this repository is your workshop.

This project reimagines the traditional exercise repository by focusing on **generative grammar drills** and **contextual error deconstruction**. Instead of multiple-choice questions, you are presented with sentence skeletons, ambiguous modifiers, and clause fragments, which you must forge into polished, coherent prose. It’s less about testing and more about *tensile strength*—the ability to bend grammatical rules without breaking meaning.

---

## 🧭 Why "Forge"? A Philosophical Shift

Most grammar tools treat language as a fragile vase—handle with care or it shatters. LexiForge treats language as a **metallic alloy**. You need heat (challenge), pressure (repetition), and annealing (feedback) to create something durable.

Our exercises are designed to build **Cognitive Grammar Muscle Memory**:
- **Resilience** against tricky subject-verb agreement.
- **Flexibility** in sentence structure transformation (active ↔ passive, simple ↔ compound).
- **Precision** in tense sequencing across complex narratives.

## ✨ Core Features: The Smithy’s Toolkit

This repository is not a static PDF dump. It is an active development hub containing the source logic, exercise datasets (in JSON/YAML), and community-tested templates. Here’s what you can expect to find within:

### 1. 🧩 Clause Assembly Forge
Break down compound-complex sentences into atomic components. Our "Matrix Puzzles" require you to identify dependent clauses, relative pronouns, and conjunction junctions. This is the heavy lifting for advanced writers.

### 2. 🎯 Ambiguity Discriminator
A specialized module built to tackle **syntactic ambiguity**—sentences with dual interpretations. You will be tasked with rewriting these to remove confusion, solidifying your understanding of modifier placement and parallelism.

### 3. ⚡ Tense Flow Simulator
Dynamic exercises that simulate a narrative timeline. You are given a series of events out of order (in plain English) and must forge a coherent paragraph using the perfect, progressive, and perfect-progressive aspects correctly. The simulator checks for logical tense anchoring, not just verb conjugation.

### 4. 🔊 Phonetic-Logic Pairing (Multilingual Support)
While the instruction language is primarily English, the **explanatory lexicons** are natively available in **Spanish, German, French, and Japanese**. This allows native speakers to understand *why* an English structure behaves differently from their L1 (First Language). Multilingual support isn't just a UI toggle; it is baked into the error analysis engine.

### 5. 🛰️ 24/7 Community Debugging Log
We maintain a "Rule Anomaly" thread where learners post sentences that seem to break standard rules. The community (that's you) helps analyze the *pragmatic* reasons behind these anomalies. This ensures the repository stays alive 24/7, powered by global time zones.

## 🚀 Getting Started: Your First Forge Session

We believe in "sink or swim" *with a lifejacket*. Here’s how to engage with the material without any technical setup barriers:

1. **Browse the `/forges` directory**—this contains the raw exercise sheets in Markdown format, sorted by skill level.
2. **Open `answer_keys/`** only *after* you have attempted the sheet. We encourage a "cold start" approach.
3. **Use the `discussions/` tab** to post your "smelted" sentences. Peer review is the primary catalysis for improvement.

## 🛠️ Contribution Guidelines: Becoming a Smith

This repo grows through the dedication of its users. If you have a knack for spotting weird grammatical edge cases or want to design a new "Forge" template, follow these protocols:

- **Fork the main branch** and create feature branches named `forge/[feature-name]`.
- **Syntax Requirements**: All new exercises must include a `metadata` header specifying `target_grammar_point`, `CEFR_level`, and `expected_time_in_minutes`.
- **Balance Principle**: For every "tricky" question you add, you must add a "core reinforcement" question to maintain a 1:3 ratio of challenge to support.
- **Code of Conduct**: We maintain a Zero-Gatekeeping policy. Constructive feedback on grammar is encouraged; pedantic corrections of dialects are not.
